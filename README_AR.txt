NEXORA CASE FILES — WEBSITE PACKAGE
===================================

الملفات:
- index.html: الصفحة الرئيسية، عرض القضايا، شرح طريقة اللعب، والأسعار.
- season-1.html: اللعبة التفاعلية للموسم الأول (6 قضايا).
- privacy.html و terms.html: صفحات قانونية أولية قابلة للتعديل.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح.
3) اضغط "ابدأ التحقيق المجاني" لتشغيل اللعبة.

النشر المجاني:
- ارفع محتويات المجلد إلى خدمة استضافة مواقع ثابتة مثل Netlify Drop أو GitHub Pages.
- يجب أن يكون index.html في جذر الموقع.
- اسمح للخدمة بنشر ملفات HTML كما هي.

ملاحظات مهمة:
- صفحة الحساب الحالية تحفظ اسم اللاعب محلياً في المتصفح فقط. ليست نظام عضويات آمناً ولا تزامن الحسابات بين الأجهزة.
- زر الشراء عرض توضيحي فقط ولا يجمع أموالاً.
- تفعيل الدفع يتطلب حساب تاجر لدى مزود متاح في بلدك، ومفاتيح API، وخادماً يتحقق من إشعارات الدفع قبل فتح المحتوى.
- تفعيل حسابات حقيقية يتطلب قاعدة بيانات وخدمة مصادقة وخادماً خلفياً.
- يجب استبدال بريد التواصل التجريبي hello@nexoracasefiles.example ببريد تملكه قبل النشر.
- راجع شروط البيع وسياسة الخصوصية بما يتوافق مع بلد نشاطك قبل استقبال المدفوعات.

هذه الحزمة هي واجهة أولية قابلة للنشر والاستعراض، وليست بعد نظاماً إنتاجياً لمعالجة المدفوعات أو بيانات الحسابات.
